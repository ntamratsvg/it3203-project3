Project Goal

My goal for this milestone was to create a functional, accessible website that explains the complexes of Cloud Computing in a way that is easy to navigate on both desktop and mobile devices. By utilizing CSS Media Queries, I ensured that the layout adapts to different screen sizes, providing a consistent user experience for all visitors.
